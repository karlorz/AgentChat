🔐 agentweb-setup

Attach-only 登录检测 · 不发送聊天 · 不关现有 tab

做什么

对已经在跑的 Chrome CDP 分类 chain.js 里每一个 Provider：ready / logged_out / org_disabled / quota / region_block_until_login / no_tab。

Never types passwords or 2FA. Default live classify should use --no-open so missing providers do not dump login tabs into the shared Chrome.

怎么跑

cd AgentChat
AGENTCHAT_NO_AUTOSTART=1 node skills/AgentChat-agentweb-setup/index.js --no-open --json

Quote the [receipt] AGENTCHAT_RUN line. Re-run after you log in yourself.
